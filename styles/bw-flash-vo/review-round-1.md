## Root cause found first

The working copy of `bw-flash-vo/style.json` has a `captions` block that is not this style's. It reads `kind: kinetic`, `font: Anton`, `size_frac: 0.115`, cream `color [246,243,234]`, gold `key_color [230,200,138]`, `chunk_sizes [2,2,3]`, `y: 0.84 anchor bottom`, `scrim: 0.45`, `depth_text.enabled: true`. The committed version (HEAD) and the README both specify `kind: staircase`, Avenir Next Bold, `size_frac 0.075`, white, `emph_color [150,20,20]`, `x 0.30 y 0.28`, `indent 0.034`, `direction alternate`, `y_up 0.74`. Restoring the HEAD captions block closes D1 to D4 and D8 to D9 in one step (`git diff HEAD -- bw-flash-vo/style.json`).
